## 🚀 Stack Tecnológico

| Tecnología | Descripción |
|------------|-------------|
| ⚛️ **React** | Interfaz moderna y dinámica para una excelente experiencia de usuario. |
| ⚡ **FastAPI** | Backend de alto rendimiento para APIs rápidas y seguras. |

## 🚀 Inicio rápido

### 1. Clonar el repositorio

```bash
git clone https://github.com/usuario/farm-web-energy.git
cd farm-web-energy
```

### 2. Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

### 3. Frontend

```bash
cd frontend
npm install
npm run dev
```
